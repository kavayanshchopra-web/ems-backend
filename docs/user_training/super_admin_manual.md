# 🛡️ Super Admin User Training Manual (EMS System)

Welcome to the **Super Admin Portal Control Manual**. As a Super Admin, you manage system-level operations, pricing configurations, and global tenants.

---

## 🔑 Key Responsibilities & Flows

### 1. **Managing Tenant Organizations & Accounts**
- **What it is:** View and coordinate companies/business tenants utilizing the system.
- **How to manage:**
  - Navigate to **Super Admin Panel** in the sidebar.
  - Review active company registers, database entries, and subscription statuses (`active`, `past_due`, `cancelled`).

---

### 2. **SaaS Billing & Plan Subscriptions**
- **What it is:** Create and modify billing plans (e.g. Free Trial, Pro, Basic) and set pricing limits (maximum channels, maximum employee profiles, and GPS permissions).
- **How to manage:**
  - Go to **SaaS Billing Portal** or **Super Admin Plans**.
  - Set limits for employees, maximum allowed WhatsApp channels, and enable/disable features like GPS Tracking.
  - Save pricing structures based on country currencies (e.g., INR for India, USD for international).

---

### 3. **Recycle Bin & System Restoration**
- **What it is:** View soft-deleted leads, employee profiles, or system logs to restore them back to active states.
- **How to manage:**
  - Open **Recycle Bin** from the sidebar controls.
  - Review deleted items list and click **`Restore`** to recover data or **`Permanently Delete`** to clean up database space.
